# Конструктор процессов и планов

Локальное веб-приложение для одного рабочего пространства. После первого запуска оно пустое: группы, процессы, проекты, дорожки и участники создаются вручную. Рабочие данные сохраняются в IndexedDB браузера и не отправляются на сервер.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`). Для проверки сборки: `npm run build`. Данные связаны с адресом страницы и профилем браузера; для переноса используйте JSON-копию.

## Работа

- **Карта процессов:** создайте группу и процесс, затем заполните текущее и целевое состояние. Этапы с датами и контрольные точки появятся на шкале. Участников и зависимости добавляйте через инспектор или панель действий.
- **План проектов:** создайте проект, поставку и хотя бы одну дорожку; затем добавляйте недельные блоки и при необходимости назначайте человека из общего справочника. Поставки допускают точный, приблизительный или неизвестный срок.
- **Связи:** поставку или блок можно вручную связать с этапом либо точкой процесса. Ссылка открывает объект в другом разделе, не меняя его сроки и статус.
- **Экспорт в Excel:** в плане выберите текущую выборку или весь план. XLSX содержит листы «Объекты плана» и «Недельный план». Импорта Excel нет.
- **Резервная копия:** меню «Данные → Скачать JSON-копию» выгружает все данные, включая скрытые фильтрами. Для восстановления выберите JSON-файл, проверьте состав и подтвердите полную замену. Можно предварительно скачать копию текущего состояния. После успешного восстановления доступна команда возврата к предыдущему состоянию.

## Формат JSON-копии

Корневой объект содержит `format: "process-planner-workspace"`, `schemaVersion: 1`, время `exportedAt` в ISO 8601 UTC, объекты `workspace` и `data`. Все 16 коллекций находятся в `data`. У каждого объекта есть устойчивый `id`, `createdAt` и `updatedAt`. Сроки задаются `DateReference` со значением `kind: "unknown"`, `"exact"` или `"range"`; словесный ориентир находится в `text`. Границы недельных блоков хранятся как даты понедельников `YYYY-MM-DD`, последняя неделя включена. При импорте проверяются версия, типы, даты, уникальность ID и все внутренние ссылки. Неизвестные версии не открываются без миграции. Восстановление заменяет весь снимок атомарно и сохраняет локальную точку возврата.

## Ограничения MVP

Один пользователь и один браузерный профиль; нет облачной синхронизации, загрузки Excel/CSV, дневного или почасового масштаба, расчёта загрузки и автоматического переноса зависимых сроков. Вложения не хранятся; ссылки на внешние документы остаются текстом.
