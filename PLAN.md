# План реализации

Источник требований: `D:\map_builder\TZ\ТЗ_визуальный_roadmap_конструктор.md` (12.10.2026). Это новая реализация с пустым рабочим пространством.

1. **Основа данных.** Общие типы всех сущностей, валидатор ссылок и дат, IndexedDB, версионированная JSON-копия, атомарное восстановление и точка возврата.
2. **Карта процессов.** Иерархия групп, процессов, этапов и контрольных точек; временная шкала, формы, инспектор, фильтры, участники и связи.
3. **План проектов.** Иерархия проектов, поставок и дорожек; недельная шкала, блоки, события, оценки, фильтры и экспорт XLSX.
4. **Интеграция.** Общее рабочее пространство, навигация и обратные межэкранные ссылки, единый визуальный язык.
5. **Проверка.** Сборка, ручной проход сценариев 1–13 из ТЗ, проверка сохранения, экспорта и восстановления; исправление найденных проблем.

Технический выбор: React + TypeScript + Vite, IndexedDB с единым атомарным снимком данных, календарные компоненты React/CSS, ExcelJS для XLSX. Рабочая разработка ведётся в каталоге `rebuild` доступной рабочей области; готовый код будет перенесён в `D:\map_builder`, где сохранены `TZ` и `.git`.
