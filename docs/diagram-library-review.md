# Библиотека визуальных схем: обзор для Map Builder

Дата обзора: 13 октября 2026 года.

## Вывод

Для ближайшей версии сохраняем **React Flow (`@xyflow/react`)**. В проекте уже реализованы собственные карточки, зоны, связи, миникарта, масштабирование и изменение размеров. Улучшение внешнего вида возможно на уровне компонентов и CSS без преобразования хранимого JSON и риска потери существующих схем.

Если позже потребуется автоматическая раскладка сложных графов, сначала имеет смысл добавить ELK в текущий редактор. Если появятся требования к более специализированным инструментам черчения, повторно сравнить AntV X6.

| Библиотека | Что даёт | Применимость здесь |
| --- | --- | --- |
| [React Flow](https://reactflow.dev/learn/customization/custom-nodes) | Произвольные React-компоненты в узлах, [группировка](https://reactflow.dev/learn/layouting/sub-flows), [мини-карта и изменение размеров](https://reactflow.dev/examples), [варианты автоматической раскладки](https://reactflow.dev/learn/layouting/layouting). | Лучшее продолжение текущего редактора: сохраняем поведение и формат данных. |
| [AntV X6](https://x6.antv.vision/en/) | Насыщенный набор [плагинов](https://x6.antv.antgroup.com/en/tutorial/plugins/selection): выделение, направляющие, миникарта, горячие клавиши и др. | Интересен для будущего режима точного построения диаграмм. Переход потребует переписать редактор и адаптер к существующему JSON. |
| [Rete.js](https://retejs.org/docs/api/overview/) | Модульный редактор графов с React-плагином и [автоматическим размещением](https://retejs.org/docs/guides/arrange/). | Лучше подходит для вычислительных и исполняемых потоков, чем для карты процессов и свободных рабочих схем. |
| [tldraw](https://tldraw.dev/sdk-features/bindings) | Сильная свободная доска с собственными фигурами и связями. | Подходит, если редактор станет ближе к whiteboard. Для публичного размещения нужна оценка [условий лицензирования](https://tldraw.dev/sdk-features/license-key). |

## Следующие практические улучшения схемы

1. Добавить автоматическую раскладку выбранного фрагмента через ELK с возможностью отмены.
2. Добавить два-три визуальных шаблона карточек для разных сценариев QA, сохранив текущие типы объектов в JSON.
3. Добавить выравнивание и распределение выделенных блоков. Это изменение интерфейса и координат, а не схемы данных.

В этой дизайн-ветке миграция движка не выполняется: данные, импорт и экспорт остаются совместимыми.
